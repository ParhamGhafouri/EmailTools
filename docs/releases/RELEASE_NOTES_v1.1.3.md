## English

# Email Tools v1.1.3

Version 1.1.3 delivers the full public release of the intelligent **Task Tracker & Workflow Automation** system, a modern **Fluent 2 redesign** for Settings and Storage Health dashboards, universal **Windows 11 rounded window geometry** across all dialogs, seamless **search banner positioning** with zero white space, and robust **subject/recipient data reliability**.

### Highlights (Ordered by Priority)

1. **Full Release of Task Tracker & Workflow Automation:**
   - **Interactive Kanban Status Dashboard:** Real-time summary cards grouping tasks into *To Do*, *In Progress*, *Waiting for Reply*, *Completed*, and *Overdue*.
   - **Visual Automation Rule Builder:** Create granular multi-condition rules targeting Incoming or Outgoing mail, Sender/Recipient addresses, Subject/Body keywords, file attachment extensions, and priority tags.
   - **Auto-Resolve on Reply:** Automatically tracks responses to pending emails and transitions task status from *Waiting* to *In Progress* or *Completed* without manual intervention.
   - **Full Thread Context & Details:** Inspect complete message subjects, senders, direct (`To`) and copied (`Cc`) recipients, deadlines, and custom notes with 1-click navigation to the source email in Outlook.
   - **UTF-8 BOM CSV/Excel Export:** High-fidelity export supporting native Persian, Arabic, and English characters.

2. **Modern Fluent 2 Settings & Storage Health Redesign:**
   - **Visual Mailbox Quota Gauges:** Real-time visual progress bars with dynamic color transitions (green/orange/critical red) reflecting live Exchange mailbox usage.
   - **Archive Drive Capacity Meters:** Clear storage indicators showing available and total disk capacity for local seasonal PST archives.
   - **Modern Card-Based Grouping:** Replaced plain text dumps with clean Fluent 2 rounded cards (`8px` corner radius) and anti-aliased perimeter borders across Light, Dark Gray, and Black themes.

3. **Universal Windows 11 Rounded Window Geometry:**
   - Enforced modern Windows 11 DWM rounded corners (`DWMWCP_ROUND`) and non-client border geometry across all dialogs, popups, message boxes, and About windows, completely eliminating sharp square popups.

4. **Seamless Message List Search Banner (Zero White Space):**
   - Symmetrically synchronized the native `OutlookGrid` position with `SearchBand`, eliminating dead white/gray gaps across all Outlook versions (including Outlook 2016, 2019, and 365) and varying DPI scaling factors.

5. **Blank Subject & Recipient Data Fixes:**
   - Resolved empty subject lines and missing recipient fields across both Advanced Search and Task Tracker, backed by an automated database backfill on startup.

**Install:** Download **EmailTools_Setup.rar**, extract it, then run **EmailTools_Setup.exe**. Setup is per-user and needs no administrator rights. Existing users can install v1.1.3 directly over the current version without uninstalling first.
