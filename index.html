Before you install

For classic Outlook 2016, 2019, 2021 or Microsoft 365 on Windows. New Outlook, Mac and web versions do not support this add-in.

Requires .NET Framework 4.8. Managed computers may need IT help with prerequisites or publisher trust.

After an upgrade, a one-time header verification pass may temporarily show Indexing. Ready returns when required verification completes.

Mail analysis runs locally. Update checks use GitHub. Keep backups of important PSTs; an archive is not a backup.
